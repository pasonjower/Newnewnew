# Retool app blueprint

This guide describes how to assemble the Jewelry Inventory Co-Pilot UI using only Retool primitives and the artifacts in this repo.

## 1. Create the workspace

1. Sign in to Retool (free tier is sufficient).
2. Create a new app named **Jewelry Inventory Co-Pilot**.
3. Under *Settings → Authentication*, enable **Email magic link**. Retool will handle the auth flow for you.

## 2. Data resources

1. Add a **Google Sheets** resource named `JewelrySheets` pointing to the sheet populated from [`docs/sample_data.md`](sample_data.md).
2. (Optional) Add a **File Uploader** resource for ad-hoc CSV ingestion.
3. Create a **Retool Workflow** named `RecomputeMetrics` that executes the Python code in [`scripts/compute_metrics.py`](../scripts/compute_metrics.py). Configure inputs for:
   - `orders_csv`
   - `products_csv`
   - `inventory_csv`
   - `locations_csv`
   - `vendor_params_csv`
   - `metal_prices_csv`

   The workflow can fetch data from Google Sheets (via `get_spreadsheet_values`) or accept uploaded files.

## 3. Layout overview

```
┌───────────────────────────────────────────────┐
│ Header: logo + "Recompute Metrics" button      │
├───────────────────────────────────────────────┤
│ KPI tiles (5 columns)                          │
├───────────────────────────────────────────────┤
│ Tabbed container:                              │
│   • Replenish Now table                        │
│   • Cut / Defer table                          │
│   • Double-Down table                          │
│   • Inventory Deep Dive (editable grid)        │
├───────────────────────────────────────────────┤
│ Slide-out drawer: Upload wizard + PO export    │
└───────────────────────────────────────────────┘
```

### Upload wizard

- Use a **Button** labeled "Upload or Connect Data" that opens a **Modal**.
- Inside the modal, add a **Segmented Control** to toggle between **CSV Upload** and **Connect Sheets**.
- For CSV mode, use six **File Input** components bound to the workflow inputs.
- For Sheets mode, display read-only instructions and a "Sync" button that fetches the latest sheet data.

### KPI tiles

- Create five **Stat** components bound to the metrics output table (Inventory Turnover, Days on Hand, % In-Stock, GM$, Aged Inventory $).
- Use conditional coloring (green/yellow/red) based on thresholds defined in the metrics payload.

### Table views

- Add **Table** components for each prioritized list. Bind them to the workflow results: `replenish_now`, `cut_defer`, `double_down`.
- Enable column filters, multi-select, and row click to open SKU detail.
- For the **Inventory Deep Dive** table, use the base inventory dataset joined with metrics. Enable **inline editing** for `lead_time_days` and `moq_units` by writing back to Google Sheets via a Retool Query.

### Draft PO export

- Place a **Button** labeled "Download Draft POs" that triggers the workflow with the `export` flag. Use `utils.downloadFile` with the CSV returned from the workflow.
- In demo mode, bind the button to download the sample file generated by `scripts/demo_runner.py` under `/outputs/draft_pos.csv`.

### SKU detail drawer (optional)

- Use a **Drawer** component bound to the selected row. Display sparkline charts (Retool Plot) for daily demand, show margin breakdown, and allow editing of safety stock multipliers.

## 4. Triggering recomputations

- The **Recompute Metrics** button should call the workflow, passing either uploaded files or pulling from Sheets.
- After success, refresh all tables and KPI tiles via `query.trigger()`.
- Show a toast with the summary message returned by `compute_metrics.py`.

## 5. Demo mode toggle

Add a boolean **Toggle** component called `useDemoData`. When `true`, short-circuit data sources to the sample CSVs bundled with the app. When `false`, read from Google Sheets / Shopify connectors.

## 6. Draft PO CSV structure

The workflow returns a base64-encoded CSV containing:

| column | description |
|--------|-------------|
| `vendor_id` | Vendor code |
| `vendor_name` | Friendly name |
| `sku` | SKU to order |
| `recommended_qty` | Rounded up to MOQ increments |
| `target_po_date` | Today + lead time |
| `projected_stockout_date` | Based on average daily demand |
| `unit_cost` | Net unit cost after metal adjustments |
| `total_cost` | `recommended_qty * unit_cost` |

Use Retool's `downloadFile` helper to let users export the CSV.

## 7. Permissions & testing

- Restrict write-back queries to ops users group.
- Leverage Retool's "Preview as" to confirm demo stakeholders only see read-only data.
- After every edit, run the `RecomputeMetrics` workflow to ensure derived tables refresh correctly.
